# Python for Data Science

Notes and practice examples for Python and its essential data science libraries.

## Libraries

- **Python** – Variables, data types, loops, functions, and data structures.
- **NumPy** – Arrays, indexing, slicing, and numerical operations.
- **Pandas** – Data manipulation, DataFrames, and data cleaning.
- **Matplotlib** – Creating graphs and visualizing data.
- **Seaborn** – Statistical data visualization and plotting.
