Data Types & When to Use What

Data is broadly either numerical or categorical. The right chart depends on which combination you're analyzing and what question you're asking.

PlotAnalysis typeUse case

012D Line Plot

bivariatenumerical vs numericaltime series

A line plot is essentially a scatter plot with the points connected — it's the natural choice when there's an inherent order to the x‑axis, like time.

a.Plotting a simple function

price = [48000,54000,57000,49000,47000,45000]
year  = [2015,2016,2017,2018,2019,2020]

plt.plot(year, price)

b.From a Pandas DataFrame

batsman = pd.read_csv('/content/sharma-kohli.csv')
batsman

plt.plot(batsman['index'], batsman['V Kohli'])

c.Plotting multiple lines

Multiple calls to plt.plot() before plt.show() draw onto the same figure.

plt.plot(batsman['index'], batsman['V Kohli'])
plt.plot(batsman['index'], batsman['RG Sharma'])

d.Title & axis labels

plt.plot(batsman['index'], batsman['V Kohli'])
plt.plot(batsman['index'], batsman['RG Sharma'])
plt.title('Rohit Sharma vs Virat Kohli Career Comparision')
plt.xlabel('Season')
plt.ylabel('Runs Scrored')

e.Colors (hex), line width / style, marker size

plt.plot(batsman['index'], batsman['V Kohli'], color='green')
plt.plot(batsman['index'], batsman['RG Sharma'], color='#F54927')
plt.title('Rohit Sharma vs Virat Kohli Career Comparision')
plt.xlabel('Season')
plt.ylabel('Runs Scrored')
plt.plot(batsman['index'], batsman['V Kohli'],
         color='green', linestyle='dashed')
plt.plot(batsman['index'], batsman['RG Sharma'],
         color='#F54927', linestyle='dashdot')

plt.title('Rohit Sharma vs Virat Kohli Career Comparision')
plt.xlabel('Season')
plt.ylabel('Runs Scrored')
plt.plot(batsman['index'], batsman['V Kohli'],
         color='green', linestyle='solid',
         linewidth=3, marker='D', markersize=10)

f.Legend & location

plt.plot(batsman['index'], batsman['V Kohli'],
         color='green', linestyle='solid', linewidth=3,
         marker='D', markersize=10, label='Virat')
plt.plot(batsman['index'], batsman['RG Sharma'],
         color='#F54927', linestyle='dashdot', linewidth=2,
         marker='o', label='Rohit')

plt.title('Rohit Sharma vs Virat Kohli Career Comparision')
plt.xlabel('Season')
plt.ylabel('Runs Scrored')

plt.legend() # loc='best' by default -> automatically decide
# plt.legend(loc='right')      other options: 'best', 'upper left', 'lower right', ...

g.Limiting axes

Useful when an outlier flattens the rest of the curve.

price = [48000,54000,57000,49000,47000,45000,450000000] # outlier flattens the rest of the curve
year  = [2015,2016,2017,2018,2019,2020,2021]

plt.plot(year, price)
# we can limit x or y
plt.ylim(0, 75000)
plt.xlim(2017, 2019)

h.Grid & show

plt.plot(batsman['index'], batsman['V Kohli'],
         color='green', linestyle='solid', linewidth=3,
         marker='D', markersize=10, label='Virat')
plt.plot(batsman['index'], batsman['RG Sharma'],
         color='#F54927', linestyle='dashdot', linewidth=2,
         marker='o', label='Rohit')

02Scatter Plot

bivariatenumerical vs numericalcorrelation

A 2D line plot is really a special case of a scatter plot, where the dots happen to be joined by a line.

a.plt.scatter — simple function

x = np.linspace(-10, 10, 50)
y = 10*x + 3 + np.random.randint(0, 300, 50)

plt.scatter(x, y)

b.plt.scatter on Pandas data

df = pd.read_csv('batter.csv')
df = df.head(50)

plt.scatter(df['avg'], df['strike_rate'], color='red', marker='+')
plt.title('Avg and Sr analysis of top 50 batsman')
plt.xlabel('Average')
plt.ylabel('Strike Rate')

c.Size — bubble plot

Dot size represents a third variable. This is slower than plt.plot.

tips = sns.load_dataset('tips')

plt.scatter(tips['total_bill'], tips['tip'], s=tips['size']*20) # dot size represents size of party
# slower

d.Scatterplot using plt.plot — faster

plt.plot(tips['total_bill'], tips['tip'], 'o') # cannot vary size, and limited color manipulation
plt.plot vs plt.scatter — plot is faster but can't vary marker size or color per point. scatter is more flexible (size, color, alpha per point) but slower to render.

e.Colored scatterplots (advanced)

iris = pd.read_csv('iris.csv')
iris.Species.unique()

plt.scatter(iris['SepalLengthCm'], iris['PetalLengthCm'])
plt.xlabel('Sepal Length')
plt.xlabel('Petal Length')
# encode the category as a number first
iris['Species'] = iris['Species'].replace({'Iris-setosa':0, 'Iris-versicolor':1, 'Iris-virginica':2})
iris.sample(5)

f.cmap and alpha + colorbar

plt.scatter(iris['SepalLengthCm'], iris['PetalLengthCm'],
            c=iris['Species'], cmap='winter', alpha=0.7)
plt.xlabel('Sepal Length')
plt.xlabel('Petal Length')
plt.colorbar()

03Bar Chart

bivariatenumerical vs categoricalaggregate analysis

a.Simple bar chart

children = [10,20,40,10,30]
colors   = ['read','blue','green','yellow','pink']
plt.bar(colors, children, color='cyan')

b.Horizontal bar chart

Preferred when the number of categories on the x‑axis grows large.

plt.barh(colors, children, color='cyan')

c.Color and label, from real data

df = pd.read_csv('/content/batsman_season_record.csv')
df
plt.bar(df['batsman'], df['2015'], width=0.5)

d.Multiple bar charts (grouped) & xticks

Matplotlib has no built‑in "grouped bar" call — offset the x‑positions manually so the bars sit side by side.

plt.bar(np.arange(df.shape[0]) - 0.2, df['2015'], width=0.2, color='cyan')
plt.bar(np.arange(df.shape[0]),       df['2016'], width=0.2)
plt.bar(np.arange(df.shape[0]) + 0.2, df['2017'], width=0.2, color='purple')
plt.xticks(np.arange(df.shape[0]), df['batsman'])

plt.show()

e.A problem — long category names & rotating xticks

# simple bar chart with a problem: long labels collide
children = [10,20,40,10,30]
colors = ['read read read read ','blue blue blue blue','green green green green',
          'yellow yellow yellow yellow','pink pink pink pink']
plt.bar(colors, children, color='cyan')

plt.xticks(rotation='vertical')

f.Stacked bar chart

Use bottom= to stack each bar series on top of the previous one's value.

df
plt.bar(df['batsman'], df['2017'], label='2017')
plt.bar(df['batsman'], df['2016'], bottom=df['2017'], label='2016')
plt.bar(df['batsman'], df['2015'], bottom=(df['2016'] + df['2017']), label='2015')

plt.legend()
plt.show()

07Plot Size & Annotations

advanced

a.Figure size

Set the figure size before plotting. Argument order is (width, height) in inches.

plt.figure(figsize=(15,7)) # 15 is width and 7 is height

plt.scatter(iris['SepalLengthCm'], iris['PetalLengthCm'], c=iris['Species'], cmap='winter', alpha=0.7)
plt.xlabel('Sepal Length')
plt.xlabel('Petal Length')
plt.colorbar()

b.Annotations with plt.text — looping over points

batters = pd.read_csv('batter.csv')
df = batters.head(100).sample(25, random_state=5)
df
plt.figure(figsize=(18,10))
plt.scatter(df['avg'], df['strike_rate'], s=df['runs'])

for i in range(df.shape[0]):
  plt.text(df['avg'].values[i], df['strike_rate'].values[i], df['batter'].values[i])

c.Annotations — manual labels with fontdict

x = [1,2,3,4]
y = [5,6,7,8]
plt.scatter(x, y)
plt.text(1, 5, 'Point 1')
plt.text(2, 6, 'Point 2')
plt.text(3, 7, 'Point 3')
plt.text(4, 8, 'Point 4', fontdict={'size':12, 'color':'brown'})

d.Horizontal & vertical reference lines

plt.figure(figsize=(18,10))
plt.scatter(df['avg'], df['strike_rate'], s=df['runs'])

plt.axhline(130, color='red')
plt.axhline(140, color='green')
plt.axvline(30, color='red')

for i in range(df.shape[0]):
  plt.text(df['avg'].values[i], df['strike_rate'].values[i], df['batter'].values[i])

08Subplots

object-oriented APIside-by-side plots

There are three common ways to build subplots in Matplotlib — syntax 1 is the basic, implicit way; the rest use the explicit object‑oriented (fig, ax) interface, which is preferred for laying out multiple plots side by side.

a.Syntax 1 — the basic way

plt.scatter(batters['avg'], batters['strike_rate'])

b.Syntax 2 — fig, ax = plt.subplots()

This is usually the one used to plot graphs side by side.

fig, ax = plt.subplots(figsize=(15,6))

ax.scatter(batters['avg'], batters['strike_rate'], color='red', marker='+')
# ax.plot(batters['avg'], batters['strike_rate'])

ax.set_title('Something')
ax.set_xlabel('Avg')
ax.set_ylabel('Strike Rate')

fig.show()

c.Grid of subplots — nrows / ncols, sharex

fig, ax = plt.subplots(nrows=2, ncols=1, figsize=(15,10), sharex=True)
fig # re-display the figure object
ax[0].scatter(batters['avg'], batters['strike_rate'], color='red')
ax[1].scatter(batters['avg'], batters['runs'])
fig

ax[0].set_title('Avg vs Strike Rate')
ax[0].set_ylabel('Strike Rate')

ax[1].set_title('Avg vs Strike Rate')
ax[1].set_ylabel('Runs')
ax[1].set_xlabel('Avg')

d.2×2 grid — index with [row, col]

fig, ax = plt.subplots(nrows=2, ncols=2, figsize=(10,10))

ax[0,0].scatter(batters['avg'], batters['strike_rate'], color='red')
ax[0,1].scatter(batters['avg'], batters['runs'])
ax[1,0].hist(batters['avg'])
ax[1,1].hist(batters['avg'])

plt.show()

e.Third way — fig.add_subplot(rows, cols, index)

fig = plt.figure()
ax1 = fig.add_subplot(2,1,1) # 2 rows, 1 col, plot #1
ax1.scatter(batters['avg'], batters['strike_rate'], color='red')

ax2 = fig.add_subplot(2,1,2) # 2 rows, 1 col, plot #2
ax2.hist(batters['avg'])

c.3D surface plot

Build a 2D grid of x/y coordinates with np.meshgrid before computing z over that grid.

x = np.linspace(-10, 10, 100)
y = np.linspace(-10, 10, 100)
xx, yy = np.meshgrid(x, y)
xx.shape
z = xx**2 + yy**2
fig = plt.figure(figsize=(12,8))
ax = plt.subplot(projection='3d')
p = ax.plot_surface(xx, yy, z, cmap='viridis')
fig.colorbar(p)
z = np.sin(xx) + np.cos(yy)

fig = plt.figure(figsize=(12,8))
ax = plt.subplot(projection='3d')
p = ax.plot_surface(xx, yy, z, cmap='viridis')
fig.colorbar(p)

10Contour Plots

A contour plot effectively makes a 3D surface 2D — it flattens the z‑dimension into colored/lined bands viewed from above.

a.contour() — line contours

z = xx**2 + yy**2
fig = plt.figure(figsize=(12,8))
ax = plt.subplot()
p = ax.contour(xx, yy, z, cmap='viridis')
fig.colorbar(p)

b.contourf() — filled contours

z = xx**2 + yy**2
fig = plt.figure(figsize=(12,8))
ax = plt.subplot()
p = ax.contourf(xx, yy, z, cmap='viridis')
fig.colorbar(p)
z = np.sin(xx) + np.cos(yy)

fig = plt.figure(figsize=(12,8))
ax = plt.subplot()
p = ax.contourf(xx, yy, z, cmap='viridis')
fig.colorbar(p)

11Heatmap

Built with plt.imshow() over a pivoted grid of values — a common pattern for visualizing a 2D frequency/aggregate table.

delivery = pd.read_csv('/content/IPL_Ball_by_Ball_2008_2022.csv')
delivery.head()
temp_df = delivery[(delivery['ballnumber'].isin([1,2,3,4,5,6])) & (delivery['batsman_run']==6)]
grid = temp_df.pivot_table(index='overs', columns='ballnumber', values='batsman_run', aggfunc='count')

12Pandas .plot()

Pandas wraps Matplotlib under the hood — call .plot(kind=...) directly on a Series or DataFrame for a quicker, more declarative API.

a.On a Series

s = pd.Series([1,2,3,4,5,6,7])
# s.plot(kind='line')
# s.plot(kind='hist')
s.plot(kind='pie')

It can also be used on a DataFrame.

tips = sns.load_dataset('tips')

b.Scatter plot — labels, marker, figsize, color, cmap

tips['size'] = tips.size + 10
tips.plot(kind='scatter', x='total_bill', y='tip', title='Cost Analysis',
          marker='+', s='size', figsize=(10,6), c='sex', cmap='viridis')

c.2D / line plot

stocks = pd.read_csv('https://raw.githubusercontent.com/m-mehdi/pandas_tutorials/main/weekly_stocks.csv')
stocks.head()
# line plot
stocks['MSFT'].plot(kind='line')
stocks.plot(kind='line', x='Date')
stocks[['Date','MSFT','FB']].plot(kind='line', x='Date')

d.Bar chart — single, horizontal, multiple

temp = pd.read_csv('/content/batsman_season_record.csv')
temp.head()
# temp.plot(kind='bar')
temp['2015'].plot(kind='bar')
tips.groupby('sex')['total_bill'].mean().plot(kind='bar')
temp.plot(kind='bar')

e.Stacked bar chart

temp.plot(kind='bar', stacked=True)

f.Histogram

# stocks.plot(kind='hist')
stocks[['MSFT','FB']].plot(kind='hist', bins=40)

g.Pie — single and multiple

df = pd.DataFrame(
    {
        'batsman':['Dhawan','Rohit','Kohli','SKY','Pandya','Pant'],
        'match1':[120,90,35,45,12,10],
        'match2':[0,1,123,130,34,45],
        'match3':[50,24,145,45,10,90]
    }
)

df.head()
df['match1'].plot(kind='pie', labels=df['batsman'].values, autopct='%0.1f%%')
# multiple pie charts — one per column
df[['match1','match2','match3']].plot(kind='pie', subplots=True, figsize=(15,8))

h.Multiple separate graphs together

stocks.plot(kind='line', subplots=True)

i.On MultiIndex DataFrames (pivot tables)

tips.pivot_table(index=['day','time'], columns=['sex','smoker'],
                  values='total_bill', aggfunc='mean').plot(kind='line')
tips.pivot_table(index=['day','time'], columns=['sex','smoker'],
                  values='total_bill', aggfunc='mean').plot(kind='bar')
tips.pivot_table(index=['day','time'], columns=['sex','smoker'],
                  values='total_bill', aggfunc='mean').plot(kind='pie', subplots=True, figsize=(20,10))
