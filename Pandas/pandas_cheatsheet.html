📦 Session 16 — Pandas Series

Creating Series

From list (default index)
pd.Series(['India', 'USA', 'Nepal'])
From list with custom index + name
pd.Series([67,57,89], index=['maths','english','science'], name='marks')
From dict (keys → index)
pd.Series({'maths':67, 'english':57}, name='Marks')
From CSV (squeeze to Series)
pd.read_csv('file.csv', index_col='col').squeeze('columns')

Series Attributes

AttributeDescription
.sizeTotal elements (includes NaN)
.dtypeData type (int64, object…)
.nameName of the Series
.is_uniqueTrue if all values are unique
.indexIndex object
.valuesNumPy array of values
.hasnansTrue if any NaN exists

Math / Stats Methods

Count (excludes NaN)
s.count() # vs .size which counts NaN
Sum & Product
s.sum() s.product()
Central tendency
s.mean() s.median() s.mode()
Spread

Full summary
s.describe()

Indexing & Slicing

Integer position
s[0] # first element s[5:16] # slice s[-5:] # last 5 (slicing only) s[::2] # every other
Fancy indexing (list of positions)
s[[1, 3, 4]]
Label indexing
s['maths'] # single label s[['maths', 'science']] # multiple
⚠ Negative integer indexing (s[-1]) doesn't work on Series; use slicing or .iloc

Editing Series Values

Set single value
s[1] = 100 s['maths'] = 80 # adds if missing
Slice assignment
s[2:4] = [15, 100]
Fancy indexing assignment
s[[0, 3, 4]] = [0, 0, 0]

Boolean Indexing

Relational operators (broadcast)
s >= 50 # returns boolean Series
Filter rows
s[s >= 50] # 50s & 100s s[s == 0] # ducks
Count matching
s[s > 200].size
Arithmetic (broadcasting)
100 - s # applies to every element

Important Series Methods

Type casting (memory saving)
s.astype('int16')
Range filter
s.between(51, 99) # inclusive both ends
Clip to range
s.clip(100, 200) # cap min/max
Value frequency
s.value_counts()
Sort values / index
s.sort_values(ascending=False) s.sort_index()
Remove duplicates
s.drop_duplicates(keep='last') s.duplicated().sum()
Missing values
s.isnull().sum() s.dropna() s.fillna(0) # fill with constant s.fillna(s.mean()) # fill with mean s.fillna(method='ffill') # forward fill s.fillna(method='bfill') # backward fill
Membership check
s.isin([49, 99]) # boolean mask
Apply function
s.apply(lambda x: x.split()[0].upper()) s.apply(lambda x: 'good' if x > s.mean() else 'bad')
head / tail / sample
s.head(5) s.tail(10) s.sample(5)
Deep copy (avoid view mutation)
s_new = s.copy()

Python Builtins & Conversion

Builtins
len(s) type(s) sorted(s) max(s) min(s)
Type conversion

📊 Session 19 — GroupBy Objects

GroupBy — Basics

Create GroupBy
genres = df.groupby('Genre') # single col duo = df.groupby(['Director','Star1']) # multi
Built-in aggregations
genres.min() genres.max() genres.sum() genres.mean()
Select col then agg
df.groupby('Genre')['Gross'].sum().sort_values(ascending=False).head(3)
Highest avg rating per genre
df.groupby('Genre')['IMDB_Rating'].mean().sort_values(ascending=False).head(1)

GroupBy Attributes & Methods

MethodDescription
len(g)Number of groups
g.size()Item count per group
g.first()First row of each group
g.last()Last row of each group
g.nth(n)Nth row (0-based)
g.get_group('Horror')All rows of group
g.groupsDict: group→index list
g.describe()Stats per group
g.sample(n, replace=True)n random rows per group
g.nunique()Unique counts per group

agg() Method

Dict — different agg per column
genres.agg({ 'Runtime':'mean', 'IMDB_Rating':'mean', 'Gross':'sum', 'Metascore':'min' })
List — multiple aggs per column
genres[['Runtime','IMDB_Rating']].agg(['min','max','mean'])
Mix — dict with lists
genres.agg({ 'Runtime': ['min','mean'], 'Gross': 'sum' })

Looping & apply() on Groups

Loop to get top movie per genre
df_top = pd.DataFrame(columns=movies.columns) for group, data in genres: top = data[data['IMDB_Rating'] == data['IMDB_Rating'].max()] df_top = pd.concat([df_top, top])
apply — custom function per group
def count_A(group): return group['Series_Title'].str.startswith('A').sum() genres.apply(count_A)
apply — rank within group
def rank_movie(group): group['genre_rank'] = group['IMDB_Rating'].rank(ascending=False) return group genres.apply(rank_movie)
apply — normalize within group
def normalize(group): mn, mx = group['IMDB_Rating'].min(), group['IMDB_Rating'].max() group['norm_rating'] = (group['IMDB_Rating'] - mn) / (mx - mn) return group genres.apply(normalize)

🔗 Session 20 — Merging & Concatenating

pd.concat

Stack vertically (axis=0, default)

MultiIndex result (with keys)
multi = pd.concat([nov, dec], keys=['Nov','Dec']) multi.loc[('Dec', 4)] # access by (key, index)
Stack horizontally (axis=1)
pd.concat([nov, dec], axis=1)

DataFrame.merge() — All Joins

Inner join (intersection)
students.merge(regs, how='inner', on='student_id')
Left join (keep all left)
courses.merge(regs, how='left', on='course_id')
Right join
students.merge(regs, how='right', on='student_id')
Outer join (all rows)
students.merge(regs, how='outer', on='student_id')
Different key names (left_on / right_on)
delivery.merge(matches, how='inner', left_on='match_id', right_on='id')
Self join (partner matching)
students.merge(students, how='inner', left_on='partner', right_on='student_id')[['name_x','name_y']]
Chain merges (3 tables)
students.merge(regs, on='student_id').merge(courses, on='course_id')
Alternate syntax
pd.merge(students, regs, how='inner', on='student_id')

🏗 Session 21 — MultiIndex Objects

Creating MultiIndex

from_tuples
idx = pd.MultiIndex.from_tuples([('cse',2019), ('cse',2020), ('ece',2019)])
from_product (cartesian product) — most common
idx = pd.MultiIndex.from_product([['cse','ece'],[2019,2020,2021,2022]]) idx.levels[0] # outer level idx.levels[1] # inner level
MultiIndex Series
s = pd.Series([1,2,3,4,5,6,7,8], index=idx) s[('cse', 2022)] # exact lookup s['cse'] # outer level slice
MultiIndex DataFrame (row index)
df = pd.DataFrame(data, index=multiindex, columns=['avg_package','students'])
MultiIndex DataFrame (column)
col_idx = pd.MultiIndex.from_product([['delhi','mumbai'],['avg_package','students']]) df = pd.DataFrame(data, index=[2019,2020,2021,2022], columns=col_idx)

stack / unstack / swaplevel

unstack — inner row index → columns
s.unstack() # Series → DataFrame df.unstack() # moves row level to column df.unstack().unstack() # → Series (fully flat)
stack — column index → rows
df.stack() df.stack().stack() # → Series
swaplevel
df.swaplevel() # swap row index levels df.swaplevel(axis=1) # swap column levels
💡 unstack moves rows→cols; stack moves cols→rows

sort_index on MultiIndex
df.sort_index(ascending=False) df.sort_index(ascending=[False,True]) # per level df.sort_index(level=1) # sort only inner
transpose

Pivot Table

Basic (default agg = mean)
