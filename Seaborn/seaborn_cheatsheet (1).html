import seaborn as sns

import plotly.express as px

tips = sns.load_dataset('tips')

1. Relational Plot figure: relplot

Used to see the statistical relation between 2 or more variables (Bivariate Analysis).

  • scatterplot axes
  • lineplot axes

Scatter Plot

# scatter plot -> axes level function
sns.scatterplot(data=tips, x='total_bill', y='tip', hue='sex', style='time', size='size')

# relplot -> figure level -> square shape
sns.relplot(data=tips, x='total_bill', y='tip', kind='scatter', hue='sex', style='time', size='size')
hue, style, size are semantics that can be added.

Line Plot

Preferred when x-axis has time.

gap = px.data.gapminder()
temp = gap[gap['country'] == 'Pakistan']

# axes level function
sns.lineplot(data=temp, x='year', y='lifeExp')

# using relplot
sns.relplot(data=temp, x='year', y='lifeExp', kind='line')

# hue -> style
temp = gap[gap['country'].isin(['India', 'Pakistan', 'China'])]
sns.lineplot(data=temp, x='year', y='lifeExp', hue='country')

# hue + style + size together
temp = gap[gap['country'].isin(['India', 'Brazil', 'Germany'])]
sns.lineplot(data=temp, x='year', y='lifeExp', hue='country', style='continent', size='continent')

Facet Plot (col / row)

Figure level function — works with relplot only (not with scatterplot/lineplot, since those are axes-level and faceting is a figure-level manipulation).

sns.relplot(data=tips, x='total_bill', y='tip', col='smoker', row='sex')
sns.relplot(data=tips, x='total_bill', y='tip', col='sex', row='day')

# col_wrap
sns.relplot(data=gap, x='lifeExp', y='gdpPercap', kind='scatter', col='year', col_wrap=3)

2. Distribution Plots figure: displot

Used for univariate analysis:

  • Used to find out the distribution
  • Range of the observation
  • Central Tendency
  • Is the data bimodal?
  • Are there outliers?

Axes level functions: histplot → kdeplot → rugplot

Histogram (univariate)

# plotting univariate histogram (axes level)
sns.histplot(data=tips, x='total_bill')

# figure level
sns.displot(data=tips, x='total_bill', kind='hist')

# bins parameter
sns.histplot(data=tips, x='total_bill', bins=20)

It's also possible to visualize the distribution of a categorical variable using the logic of a histogram. Discrete bins are automatically set for categorical variables (acts like a countplot):

sns.displot(data=tips, x='day', kind='hist')

hue parameter

sns.displot(data=tips, x='tip', kind='hist', hue='sex')

# element -> step
sns.displot(data=tips, x='tip', kind='hist', hue='sex', element='step')

titanic = sns.load_dataset('titanic')
sns.displot(data=titanic, x='age', kind='hist', element='step', hue='sex')

Faceting using col and row — does not work on histplot function (must use figure-level displot):

sns.displot(data=titanic, x='age', kind='hist', element='step', col='sex')

KDE Plot

Rather than using discrete bins, a KDE plot smooths the observations with a Gaussian kernel, producing a continuous density estimate.

sns.kdeplot(data=tips, x='total_bill')              # y-axis -> density
sns.displot(data=tips, x='total_bill', kind='kde')   # y-axis -> density

# hue -> fill
sns.kdeplot(data=tips, x='total_bill', hue='sex', fill=True)

Rug Plot

Plot marginal distributions by drawing ticks along the x and y axes. This function is intended to complement other plots by showing the location of individual observations in an unobtrusive way.

sns.kdeplot(data=tips, x='total_bill')
sns.rugplot(data=tips, x='total_bill')

Bivariate Histogram

A bivariate histogram bins the data within rectangles that tile the plot and then shows the count of observations within each rectangle with the fill color.

# sns.histplot(data=tips, x='total_bill', y='tip')
sns.displot(data=tips, x='total_bill', kind='hist', y='tip')

Bivariate KDE Plot

A bivariate KDE plot smoothes the (x, y) observations with a 2D Gaussian.

sns.kdeplot(data=tips, x='total_bill', y='tip')

3. Matrix Plot

  • heatmap axes (no figure-level version)
  • clustermap

Heatmap

Plot rectangular data as a color-encoded matrix.

temp_df = gap.pivot(index='country', columns='year', values='lifeExp')

plt.figure(figsize=(15, 15))
sns.heatmap(temp_df)

# annot
temp = gap[gap['continent'] == 'Europe'].pivot(index='country', columns='year', values='lifeExp')
plt.figure(figsize=(15, 15))
sns.heatmap(temp, annot=True)

# linewidth
plt.figure(figsize=(15, 15))
sns.heatmap(temp, annot=True, linewidth=0.5)

# cmap
plt.figure(figsize=(15, 15))
sns.heatmap(temp, annot=True, linewidth=0.5, cmap='viridis')

Clustermap

Plot a matrix dataset as a hierarchically-clustered heatmap. This function requires scipy to be available.

temp = px.data.iris()
sns.clustermap(temp.iloc[:, [0, 1, 2, 3]])

Categorical Plots figure: catplot

Categorical Scatter Plot

  • stripplot
  • swarmplot

Categorical Distribution Plots

  • boxplot
  • violinplot

Categorical Estimate Plot (for central tendency)

  • barplot
  • pointplot
  • countplot

Strip Plot

# strip plot -> axes level function
sns.stripplot(data=tips, x='day', y='total_bill', jitter=False)

# using catplot -> figure level function
sns.catplot(data=tips, x='day', y='total_bill', kind='strip')

# jitter + hue
sns.stripplot(data=tips, x='day', y='total_bill', jitter=0.2, hue='sex')

Swarm Plot

Better representation than strip plot — better for small dataset, not good for large dataset.

sns.catplot(data=tips, x='day', y='total_bill', kind='swarm')

# hue
sns.swarmplot(data=tips, x='day', y='total_bill', hue='sex')

Box Plot

A boxplot is a standardized way of displaying the distribution of data based on a five number summary ("minimum", first quartile [Q1], median, third quartile [Q3] and "maximum"). It can tell you about your outliers and what their values are. Boxplots can also tell you if your data is symmetrical, how tightly your data is grouped, and if and how your data is skewed.

sns.boxplot(data=tips, x='sex', y='total_bill')

# Using catplot
sns.catplot(data=tips, x='sex', y='total_bill', kind='box')

# hue
sns.boxplot(data=tips, x='day', y='total_bill', hue='sex')

# single boxplot -> numerical col only
sns.boxplot(data=tips, y='total_bill')

Violin Plot = (Boxplot + KDEplot)

sns.violinplot(data=tips, x='day', y='total_bill')

sns.catplot(data=tips, x='day', y='total_bill', hue='sex', kind='box')

# hue + split
sns.violinplot(data=tips, x='day', y='total_bill', hue='sex', split=True)

Bar Plot

# some issue with errorbar
import numpy as np
sns.barplot(data=tips, x='sex', y='total_bill', hue='smoker', estimator=np.min)

sns.barplot(data=tips, x='sex', y='total_bill')

Point Plot

Bar plot style — bars connected with lines.

# point plot -> bar plot - bars and connect bars
sns.pointplot(data=tips, x='sex', y='total_bill', hue='smoker', ci=None)
When there are multiple observations in each category, it also uses bootstrapping to compute a confidence interval around the estimate, which is plotted using error bars.

Count Plot

A special case for the bar plot is when you want to show the number of observations in each category rather than computing a statistic for a second variable. This is similar to a histogram over a categorical, rather than quantitative, variable.

sns.countplot(data=tips, x='sex', hue='day')

Faceting using catplot

sns.catplot(data=tips, x='sex', y='total_bill', col='smoker', kind='box', hue='sex', row='time')

Regression Plots figure: lmplot

  • regplot axes
  • lmplot figure

In the simplest invocation, both functions draw a scatterplot of two variables, x and y, and then fit the regression model y ~ x and plot the resulting regression line and a 95% confidence interval for that regression.

# axes level - hue parameter is NOT available
sns.regplot(data=tips, x='total_bill', y='tip')

# figure level
sns.lmplot(data=tips, x='total_bill', y='tip', hue='sex')

# residplot
sns.residplot(data=tips, x='total_bill', y='tip')

A second way to plot Facet plots → FacetGrid

Figure level equivalents that support faceting: relplot, displot, catplot, lmplot.

sns.catplot(data=tips, x='sex', y='total_bill', kind='violin', col='day')

g = sns.FacetGrid(data=tips, col='day', hue='sex')
g.map(sns.violinplot, 'sex', 'total_bill')
g.add_legend()
height and aspect params can control the size of each facet.

Plotting Pairwise Relationship (PairGrid vs Pairplot)

sns.pairplot(iris, hue='species')

# pair grid + g.map
g = sns.PairGrid(data=iris, hue='species')
g.map(sns.scatterplot)

# map_diag -> map_offdiag
g = sns.PairGrid(data=iris, hue='species')
g.map_diag(sns.histplot)
g.map_offdiag(sns.scatterplot)

# map_diag -> map_upper -> map_lower
g = sns.PairGrid(data=iris, hue='species')
g.map_diag(sns.histplot)
g.map_upper(sns.kdeplot)
g.map_lower(sns.scatterplot)
vars parameter can be used to select a subset of columns to plot.

JointGrid vs Jointplot

sns.jointplot(data=tips, x='total_bill', y='tip')

sns.jointplot(data=tips, x='total_bill', y='tip', kind='kde')

sns.jointplot(data=tips, x='total_bill', y='tip', kind='hist', hue='sex')

g = sns.JointGrid(data=tips, x='total_bill', y='tip')
g.plot(sns.scatterplot, sns.violinplot)

Notes

  • Faceting (col, row, col_wrap) only works with figure-level functions — not axes-level.
  • relplot is square shaped.
  • heatmap is axes level — no figure-level version exists.
  • clustermap requires scipy.
